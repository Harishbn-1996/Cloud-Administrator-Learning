## Project 1: Windows Firewall Status Checker

**Purpose:** Learn how to check Windows Firewall status using PowerShell.

**Script:** `Check-Firewall.ps1`

**Command used:**
```powershell
Get-NetFirewallProfile | Select-Object Name, Enabled
```
